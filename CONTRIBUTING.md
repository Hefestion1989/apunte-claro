# Contribuir a Apunte Claro

Gracias por ayudar a mejorar una herramienta abierta de estudio.

## Antes de proponer un cambio

- No incluyas apuntes, evaluaciones, documentos académicos ni datos personales.
- Usá materiales ficticios o mínimos en ejemplos y pruebas.
- Conservá la distinción entre preparar el paquete y procesarlo con una IA
  externa.
- No prometas que una IA será infalible ni que conoce lo que evaluará un docente.
- Priorizá lenguaje comprensible para estudiantes sin experiencia técnica.

## Desarrollo

```bash
npm install
npm run dev
```

Antes de enviar un cambio:

```bash
npm test
npm run lint
```

Describí qué problema resuelve el cambio y cómo lo verificaste.
