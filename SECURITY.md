# Seguridad y privacidad

## Reportar un problema

No publiques materiales académicos, datos personales ni información sensible en
un issue.

Para vulnerabilidades que puedan exponer archivos o contenido del usuario,
utilizá la opción **Report a vulnerability** de GitHub si está disponible en el
repositorio. Si no lo está, contactá al responsable desde su perfil de GitHub
sin adjuntar documentos reales.

## Alcance de privacidad

- Apunte Claro procesa y organiza el material dentro del navegador.
- La aplicación no envía archivos automáticamente a servicios externos.
- Copiar, descargar o adjuntar un paquete es una acción iniciada por el usuario.
- Las herramientas externas aplican sus propias condiciones y políticas.
- No deben incorporarse secretos ni claves de API al código del cliente.
